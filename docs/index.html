Local only · single binary · no network

Hide what matters before you paste.

Cuddio hides secrets and PII (personally identifiable information) in logs, .env files and MySQL, PostgreSQL and SQLite dumps before you share them with AI tools. Values become placeholders like <EMAIL_1>, so the AI can still tell them apart, and cuddio restore puts the real values back into its answer.

Cuddio /KITH-yo/ Welsh for to hide. The dd is the th in this.

Install

One binary for Linux, macOS and Windows (amd64 and arm64), with no runtime to install. Or download it from GitHub Releases.

Homebrew
brew install phoenix1331/tap/cuddio
Scoop (Windows)
scoop bucket add phoenix1331 https://github.com/phoenix1331/scoop-bucket
scoop install cuddio
Go 1.26 or later
go install github.com/phoenix1331/cuddio@latest

Homebrew, Scoop and the release download need nothing else installed. go install needs Go 1.26 or later, and puts cuddio in Go's bin folder ($(go env GOPATH)/bin), which needs to be on your PATH; the README has step-by-step instructions.

Quick start

$ cat storage/logs/laravel.log | cuddio      # clean stdin to stdout
$ cuddio app.log -o app.clean.log           # write to a new file, never the input
$ cuddio --clip                             # clean the clipboard in place

Try it on the fake files in examples/, which have a command for each.

Why Cuddio

Developers paste logs, stack traces, config and database dumps into AI chats every day, and those often hold API keys and passwords as well as customers' emails, phone numbers and names. Sending personal data to a third-party AI service can breach UK GDPR and company policy, even when nobody meant any harm. Cuddio cleans the text first, on your machine.

Reversible placeholders

The same value always gets the same token, so the AI can reason about which customer is which. cuddio restore swaps the real values back into its answer.

SQL-aware

Reads CREATE TABLE and INSERT columns, hides every value in sensitive columns, and keeps the dump valid SQL. Fake mode writes realistic values so it still imports.

Clipboard, including WSL

cuddio --clip cleans whatever you just copied, with UTF-8 kept intact on Windows, WSL, macOS and Linux.

Laravel and PHP aware

APP_KEY, .env files, PDO DSN passwords, log context payloads and session tables, without being PHP-only.

Built for CI

--check exits 1 when anything would be hidden and prints counts only. Values are never printed in errors or reports.

Single binary, no network

No Python or Node runtime. The test suite fails if any network code is linked into the binary.

What it does

SQL dumps

MySQL and MariaDB, PostgreSQL (including COPY blocks) and SQLite dumps, streamed in bounded memory. Every value in a sensitive column is hidden whole, pattern rules still run on every string, and the output stays valid SQL. The dialect is detected from the dump's header.

$ cuddio dump.sql -o dump.clean.sql
$ cuddio dump.sql --mode fake  # realistic fakes
$ cuddio dump.sql --dialect postgres

Put the real values back

Clean with --map to keep the placeholder mapping for the session: an owner-only file in your cache directory that expires after an hour. Paste the AI's reply into cuddio restore and the real values come back. Placeholders Cuddio never handed out are left alone.

$ cuddio app.log --map
$ cuddio restore < ai-answer.md
$ cuddio forget  # delete it now

Clean the clipboard

Copy, clean, paste. cuddio --clip works on Windows, WSL, macOS and Linux (wl-clipboard, xclip or xsel), and restore --clip puts the values back, kept out of Windows clipboard history.

$ cuddio --clip
$ cuddio restore --clip

Checks in CI

--check exits 1 when anything would be hidden; --report counts by rule. Neither ever prints a value, so they are safe in public build logs. Exit code 2 means an error, so a pipeline can tell "would redact" from "broke".

$ cuddio --check fixtures/support-log.txt
$ cuddio --report fixtures/support-log.txt
$ cuddio rules --category pii

Your own rules

A .cuddio.yaml in your project adds custom rules, allowlist entries and sensitive columns, and switches rules on or off. A global file in your config directory applies everywhere; the project file wins.

Configuration

Cuddio reads cuddio/config.yaml in your config directory (~/.config, ~/Library/Application Support or %AppData%), then the nearest .cuddio.yaml, walking up to the repository root. --config FILE uses a file of your choice instead of the project one. Unknown settings are errors, and errors never repeat values from the file.

# .cuddio.yaml
mode: placeholder
rules:
  enable: [uk-postcode]
  disable: [high-entropy-assignment]
  custom:
    - id: internal-host
      category: secret
      label: HOST
      pattern: '[a-z]+\.internal\.example\.com'
allowlist:
  values: [hello@example.com]
  patterns: ['^test-']
sql:
  columns: [notes]
  tables:
    orders: [delivery_instructions]
mapping:
  ttl: 30m
KeyDefaultMeaning
modeplaceholderplaceholder (reversible tokens) or fake (realistic fake values); --mode overrides it
placeholder.format<{label}_{n}>Token format; must contain {label} and {n}
rules.enable, rules.disablenoneRule IDs, categories (secret, pii) or gitleaks; IDs override categories
rules.customnoneYour own rules: id, category, label and an RE2 pattern, with an optional (?P<value>...) group to hide only part of a match
allowlist.values, allowlist.patternsnoneValues never hidden, exactly or by RE2 pattern; reserved domains, loopback addresses and vendor documentation keys are always allowed
sql.columnsnoneExtra sensitive columns in every table
sql.tablesnoneExtra sensitive columns per table
mapping.ttl1hHow long a --map mapping lasts
mapping.disabledfalseRefuse to store mappings; either file can set it and neither can unset it

Security and your data

Nothing is sent

Cuddio never makes a network connection. The tests fail if a network package is imported or any network code is linked into the binary.

Your input is never changed

Input files are only read. -o writes a new file through a temporary file and refuses the input itself, even through a link.

Mappings are opt-in

Only --map stores anything: an owner-only, unencrypted file in your cache directory that expires after an hour. cuddio forget deletes it now.

Values stay out of output

Errors, --check and --report never print a matched value, and config errors never repeat what is in your config.

Use at your own risk. Redaction is best effort: a clean result is not a guarantee that no secret or personal data remains, so review the output before you share it. Cuddio reduces the risk of sharing personal data; it does not by itself make sharing it compliant with UK GDPR. It does not detect names or addresses in free text, or secrets with no recognisable shape. The copy you made before running --clip stays in any clipboard history.

Details, and how to report a problem privately, are in SECURITY.md.
